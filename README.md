AI Chatbot 🤖

A personal AI chatbot built with Python, Gradio, Google Gemini, Tavily Search, and SQLite.

Features

- 💬 AI conversations using Google Gemini
- 🔎 Web search for up-to-date information
- 📅 Date function that returns today's date when the user asks for it
- 🧠 Conversation memory using SQLite
- 🗂️ Previous chat history
- 🆕 New chat functionality
- 🌐 Gradio web interface

Technologies

- Python
- Gradio
- LangChain
- Google Gemini API
- Tavily Search API
- SQLite
- LangGraph

How It Works

The user sends a message through the Gradio interface.

The AI agent processes the message using Google Gemini and can use Tavily Search when current information is required.

When the user explicitly asks for today's date, the chatbot uses its date function to return the current date.

Chat history is stored using SQLite and can be loaded through previous chat sessions.
